## What I'm focused on right now

- **Modern React architecture.** React 19 and the Next.js 16 App Router: Server Components, Server Actions, streaming and partial rendering, with a clear split between server and client code.
- **Type safety end to end.** Strict TypeScript everywhere, with **Zod** schemas validating forms, API responses and CMS content at the boundaries, so that runtime data matches compile-time types.
- **Headless and API-first content.** Structured content models, typed queries, live preview and visual editing for editors, and ISR or on-demand revalidation so content changes go live without full rebuilds.
- **AI agents and LLM features.** Designing agent-based workflows, integrating LLMs into real user flows (assistants, content tooling, smart search) and writing prompts that are reliable and testable rather than lucky.
- **Quality as a habit.** Unit and component tests with Vitest and Testing Library, end-to-end flows with Playwright, automated accessibility checks with axe, and consistent code style enforced by ESLint and Prettier.

## How I work

- **Component-driven.** Reusable components and design systems documented in Storybook, so teams build features from shared building blocks.
- **Mobile-first and accessible.** Responsive layouts from the smallest screen up, semantic HTML and automated axe checks in the pipeline.
- **Performance and SEO by default.** Core Web Vitals, image and font optimisation, metadata, OpenGraph and structured content planned in from the start.
- **API-first thinking.** Headless architectures where content, commerce and front-end are decoupled and can evolve independently.
- **AI where it adds value.** AI-assisted development for speed, and AI agents in products where they solve a real user problem.
- **Business to technical.** Translating stakeholder needs into clear technical solutions, and communicating trade-offs openly in agile, cross-functional teams.
